COMPUTER NETWORK
NETWORKING BASIC COMMANDS- 
 1. /hostname = to check the name of host computer
 2. /ipconfig -all = to see all the present ip of the computer
 3. /getmac = to see the mac addresses
 5. /nslookup website_address = to query Domain name system for domain, ips
 6. /nslookup x.x.x.x = to query Domain name system for domain, ips
 7. /ipconfig /displaydns = presents caches dns
 8. /ping website_address = to ping any address
